添付された申請書（経費精算申請書・出張申請書・稟議書のいずれか）から、書かれている値を読み取って JSON で出力してください。決まり: (1) 書類に書かれている値だけを使う。計算・推測・補完はしない。金額の合計を計算し直したり、書かれていない値を埋めたりしない。 (2) 空欄の項目は、文字列なら空文字、数値と日付なら null にする。その書類の種類に無い項目も同じ。 (3) type は、経費精算申請書なら keihi、出張申請書なら shucchou、稟議書なら ringi。 (4) 日付は YYYY-MM-DD の形にする。 (5) 金額は円の整数にする（カンマと「円」は付けない）。amount は「申請金額」欄の値をそのまま入れる。 (6) items は明細の行を上から順に、すべてのページの分を入れる。各行は name（品名）、category（費目）、amount（金額）、note（備考。空欄なら空文字）。 (7) attachments は「添付書類」欄で印（■ またはレ点）が付いている書類名だけを入れる。□ のままの書類は入れない。欄が無ければ空の配列にする。 (8) approver_position は決裁者欄の役職（課長・部長・役員）、approver_name は氏名。 (9) applicant_class は「役職区分」欄の値（一般・管理職）。 (10) participants は「参加人数」欄の数字だけ。空欄なら null。 (11) external_participants は「社外の参加者」欄で「有」に印があれば 有、「無」に印があれば 無、どちらにも印が無いか欄が無ければ空文字。 (12) nights は「宿泊数」欄の数字だけ。quotes_count は「見積書の社数」欄の数字だけ。空欄や欄が無いときは null。 (13) destination は「出張先」欄の値をそのまま入れる。 (14) 出力は JSON だけにする。出力する項目は次の 20 個すべて。どの種類の書類でも 20 個を必ず出す: type, applicant, department, applicant_class, apply_date, amount, items, purpose, approver_position, approver_name, attachments, quotes_count, pay_date, participants, external_participants, destination, depart_date, return_date, nights, subject。申請書:
