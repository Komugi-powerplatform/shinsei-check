添付された申請書（経費精算申請書・出張申請書・稟議書のいずれか）から、書かれている値を読み取って JSON で出力してください。

決まり:
- 書類に書かれている値だけを使う。計算・推測・補完はしない。金額の合計を計算し直したり、書かれていない値を埋めたりしない。
- 空欄の項目は、文字列なら ""、数値と日付なら null にする。その書類の種類に無い項目も null にする。
- type は、経費精算申請書なら "keihi"、出張申請書なら "shucchou"、稟議書なら "ringi"。
- 日付は YYYY-MM-DD の形にする。
- 金額は円の整数にする（カンマと「円」は付けない）。amount は「申請金額」欄の値をそのまま入れる。
- items は明細の行を上から順に入れる。
- attachments は「添付書類」欄で ■ が付いている書類名だけを入れる。□ の書類は入れない。欄が無ければ空の配列にする。
- approver_position は決裁者欄の役職（課長・部長・役員）、approver_name は氏名。
- participants は「参加人数」欄の数。空欄なら null。
- 出力は JSON だけにする。
